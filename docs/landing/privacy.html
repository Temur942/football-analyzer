2. Какие данные обрабатываются

Оператор обрабатывает минимальный объём данных, необходимый для работы

Сервиса:

  • Идентификатор Telegram (`telegram_id`) — необходим для направления

сообщений и определения подписки.

  • Имя пользователя Telegram (username), если оно открыто самим

пользователем.

  • Сведения о подписке: дата начала и окончания доступа, статус оплаты.
  • Сведения о платежах: идентификатор платежа, сумма, дата, статус.

Полные реквизиты банковской карты Оператором не хранятся — их обрабатывает

платёжная система ЮKassa.

  • Технические данные: записи о работе Сервиса (время обращения,

идентификатор бота, диагностические сообщения об ошибках).

Оператор не собирает биометрические данные, данные о здоровье, паспортные

данные, адрес, телефон, геолокацию, а также данные детей.

4. Локализация и хранение данных

4.1. Базы данных, содержащие персональные данные Пользователей, размещены

на территории Российской Федерации (ч. 5 ст. 18 152-ФЗ).

4.2. Оператор не создаёт и не ведёт базы данных с персональными данными

российских граждан за пределами РФ.

5. Трансграничная передача

5.1. Для направления сообщений Пользователю Оператор передаёт его

`telegram_id` и текст сообщения сервису Telegram (Telegram Messenger Inc.),

который находится за пределами Российской Федерации (ст. 12 152-ФЗ).

5.2. Такая передача осуществляется на основании согласия Пользователя,

получаемого до начала использования Сервиса (соответствующий текст приведён в

Сервисе при первом запуске).

5.3. Оператор направляет в уполномоченный орган уведомление о трансграничной

передаче персональных данных в порядке, установленном законодательством.

5.4. Иные персональные данные за пределы РФ не передаются.

7. Сроки хранения и удаление

  • `telegram_id` и сведения о подписке — в течение срока использования

Сервиса и до удаления данных по запросу Пользователя.

  • Сведения о платежах — в сроки, установленные законодательством о налогах

и сборах.

  • Технические журналы — не дольше срока, необходимого для обеспечения

безопасности и разбора инцидентов.

По достижении целей обработки либо по обоснованному запросу данные удаляются или

обезличиваются, за исключением данных, хранение которых требуется по закону.

копирование, ограничение перечня обрабатываемых данных. Абсолютная безопасность

не может быть гарантирована ни одним способом передачи или хранения данных;

Оператор обязуется своевременно реагировать на инциденты.
