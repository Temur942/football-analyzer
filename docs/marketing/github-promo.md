## 1. Что открываем

Каталог `tools/cardkit` — генератор карточек прогнозов, лицензия MIT.
Это самостоятельный проект, который можно предлагать в подборки.

**Ссылка для PR:** `https://github.com/Temur942/football-analyzer/tree/main/tools/cardkit`

## 3. Что писать в PR — правила

- Сначала прочитать CONTRIBUTING.md репозитория, если он есть.
- Одна строка, в стиле соседних (не «наш продукт», а «что делает»).
- Без ссылок на коммерческий сайт в описании строки — модераторы это не любят.
- Ссылка на сайт — в README библиотеки, а не в самой строке списка.

## 4. Чего ждать

- GitHub-ссылки **nofollow**: SEO-веса почти нет.
- Реальный эффект — переходы разработчиков и упоминания.
- Часть PR отклонят. Это нормально: цель — 2–3 принятых из 5.

## 5. Что нужно от вас

1. Создать (или разрешить создать) репозиторий `cardkit` — нужен токен GitHub
   с правами `repo`, у меня его нет.
2. Отправить PR через веб-интерфейс GitHub (5 минут на каждый) —
   тексты выше готовы.
