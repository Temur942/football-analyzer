# Контент-план канала (первые 2 недели)

Ритм: **1 пост в день в будни, 2 в выходные**. Время — МСК.
Главный принцип: не «много прогнозов», а **один прогноз + объяснение**.

## Рубрики

| Рубрика | Что это | Частота |
|---|---|---|
| **Прогноз дня** | один матч, полная раскладка в процентах | ежедневно |
| **Разбор** | почему модель дала такие цифры | 2 раза в неделю |
| **Итоги** | сколько прогнозов зашло, честно | раз в неделю |
| **Как считается** | простая математика модели для неспециалистов | 2 раза в неделю |
| **Новости модели** | что улучшили, какие линии скрыли | по факту |

## Неделя 1

**День 1 — знакомство**
```
⚽ Что это за канал

Я считаю вероятности футбольных матчей — не «ставлю», а считаю.
3 сезона истории, 20 000+ матчей, модель Пуассона с поправкой на низкие счета.

Каждый день — один матч с полной раскладкой: тотал, исход, счёт, углы, карточки.
Бот присылает то же самое за 5 часов до матча: @footballizator_bot

18+. Вероятности, не гарантии.
```

**День 2 — прогноз дня + разбор**
Прогноз одного матча (взять из бота) + 3-4 строки «почему так».

**День 3 — как считается**
```
Как модель понимает силу команды

Атака = сколько команда забивает относительно среднего по лиге.
Защита = сколько пропускает относительно среднего.
Старые матчи весят меньше: то, что было два года назад, важно вдвое меньше.

Просто: не «экспертное мнение», а отношение к среднему.
```

**День 4 — прогноз дня**

**День 5 — разбор ошибки**
Взять любой прогноз, который не зашёл, и объяснить: вероятность 70% ≠ гарантия.

**День 6 — два прогноза (выходной) + итоги недели**
```
Итоги недели: 6 прогнозов, зашло 4.
Это нормальный результат для вероятностей — 70% не значит «всегда».
```

**День 7 — как считается: тоталы и Пуассон**
Коротко, на пальцах, без формул.

## Шаблон поста «Прогноз дня»

```
⚽ {Лига}: {Команда} — {Команда}
🕐 {дата, время} МСК

🎯 Исход: П1 {N}% · Х {N}% · П2 {N}%
🥅 Тотал 2,5 — {N}%
⏱ ТБ 0,5 в 1-м тайме — {N}%
🔮 Вероятный счёт: {1:1} — {N}%

Полная раскладка (углы, карточки, голы команд) — в боте за 5 часов до матча:
@footballizator_bot

18+. Вероятности, не гарантии.
```

## Метрики канала

- переходы в бота (`t.me/...?start=ch` — utm через start-параметр),
- `/start` → согласие,
- просмотр тарифа → оплата,
- отписки после постов с «прогноз не зашёл» (нормально, если меньше 1%).

## Чего не делать

- Не публиковать больше 2 прогнозов в день — канал превращается в ленту шума.
- Не удалять провалившиеся прогнозы. Удалённый провал = потерянное доверие.
- Не писать «гарантированный заход», «100%», «заработай».
- Не размещать рекламу букмекеров.
