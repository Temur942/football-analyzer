# 10 сообщений для разных чатов

Правило для всех: сначала по делу, потом ссылка. Одно сообщение — один чат.
Не спамить, не повторять, не писать «залетай срочно».

---

## 1. Чат болельщиков АПЛ

**Когда:** в обсуждении конкретного матча тура.

```
Перед туром посчитал вероятности по матчам АПЛ — не «прогнозы», а цифры:
тотал, углы, карточки. Например, на Сити — Фулхэм: ТБ 2,5 — 54%,
углы ТБ 9,5 — 62%, меньше 4,5 карточек — 71%.

Считается по трём сезонам, обновляется каждый час:
https://footballinho.ru/match-center/

18+, это аналитика, а не советы по ставкам.
```

---

## 2. Чат РПЛ

**Когда:** после тура, когда спорят «сколько было углов».

```
Интересный момент: углы предсказуемее, чем кажется. У каждой лиги своя база
(в РПЛ ниже, чем в АПЛ), и стиль команды её двигает.

Считаю такую статистику по матчам — вот пример по ближайшим:
https://footballinho.ru/guide/corners/

Если интересно по своей команде — бот @footballizator_bot, первые 3 дня бесплатно.
```

---

## 3. Чат Лиги чемпионов

**Когда:** перед игровым днём ЛЧ.

```
К еврокубкам отдельная логика: нельзя сравнивать «среднюю по лиге» —
команды из разных чемпионатов. Поэтому сила лиг считается отдельно,
по матчам самих еврокубков.

Разложил ближайшие матчи по вероятностям:
https://footballinho.ru/line/

18+, аналитика.
```

---

## 4. Чат «ставки и прогнозы»

**Когда:** только если правила чата не запрещают ссылки. Осторожно.

```
Не даю «заходы» и не продаю ставки. Считаю вероятности и показываю их
открыто: сколько по модели ждать голов, углов, карточек.

Интересно тем, кто сам решает, а не ищет «гарантию»:
https://footballinho.ru/about.html

Если модератор против ссылок — удалите, без обид.
```

---

## 5. Чат аналитики и статистики

**Когда:** в разговоре про модели и данные.

```
Собрал модель на 3 сезонах: сила атаки/защиты с затуханием, Пуассон
с поправкой Диксона–Коулза, отдельные оценки для углов и карточек.

Честно про пределы: на исторических коэффициентах рынок точнее модели
примерно на 3%. Поэтому это аналитика вероятностей, а не «обыгрываем букмекера».

Посмотреть, как считает: https://footballinho.ru/guide/probabilities/
```

---

## 6. Фэнтези-чат

**Когда:** перед туром, в разговоре о выборе игроков.

```
Для фэнтези полезны вероятности голов команд — видно, у кого ожидаемая
атака выше в конкретном матче, а не «по ощущениям».

Раскладка по ближайшим матчам: https://footballinho.ru/line/
```

---

## 7. Чат «матчи сегодня»

**Когда:** утром, когда спрашивают «что сегодня играют».

```
Собрал все матчи на сегодня-завтра с вероятностями:
https://footballinho.ru/live/   — счёт в реальном времени
https://footballinho.ru/line/   — прогнозы по турнирам

Обновляется само, смотреть ничего не нужно.
```

## 8. Чат любителей статистики углов

**Когда:** спор про конкретную линию углов.

```
По углам важна база лиги: в Чемпионшипе углов больше, чем в Серии A.
И линии около среднего (8,5–9,5) предсказываются хуже всего — проверил,
сложные поправки не помогают.

Почему так: https://footballinho.ru/guide/corners/
```

---

## 9. Чат обсуждения коэффициентов

**Когда:** в разговоре про цену и маржу. Без рекламы БК.

```
Полезная штука: сравнивать вероятность с ценой. Если модель даёт 54%,
а коэффициент 1,7 — это одно, а 1,9 — другое.

Как читать проценты, чтобы не путать их с обещанием:
https://footballinho.ru/guide/probabilities/
```

---

## 10. Чат сборных / товарищеских матчей

**Когда:** перед окном сборных.

```
В товарищеских матчах модель слабее: мотивация и составы непредсказуемы,
а история команд пересекается редко. Поэтому к таким матчам отношусь
осторожнее, чем к клубным.

Вот что считается по ближайшим: https://footballinho.ru/match-center/
```

## Чего не делать

- Не постить две ссылки в один чат за день.
- Не писать «гарантия», «100%», «заход», «заработай».
- Не рекламировать букмекеров.
- Не писать в личку участникам.
- Если чат запрещает ссылки — не спорить, уйти.
