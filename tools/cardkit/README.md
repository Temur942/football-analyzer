# cardkit — карточки футбольных прогнозов

Генерирует PNG 1080×1350 для постов в Telegram и ВК: команды, время, полоски
вероятностей. Всё рисуется кодом — никаких стоковых фото, никаких чужих прав.

## Установка

```bash
pip install pillow
```

## Использование

```bash
python cardkit.py \
  --home "Зенит" --away "Спартак" \
  --kickoff "23.11, 19:30 МСК" \
  --competition "РПЛ (Россия)" \
  --line "Тотал 2,5:0.54" --line "Углы 9,5:0.62" --line "ЖК 4,5:0.71" \
  --out card.png
```

Или из Python:

```python
from cardkit import render_card
from pathlib import Path

render_card(
    home="Зенит", away="Спартак", kickoff="23.11, 19:30 МСК",
    lines=[("Тотал 2,5", 0.54), ("Углы 9,5", 0.62)],
    out_path=Path("card.png"),
)
```

## Зачем

Каналам нужны визуалы каждый день, а брать фото матчей из стока нельзя:
на кадрах клубные эмблемы и лица игроков. Здесь картинка своя и цифры внутри.
